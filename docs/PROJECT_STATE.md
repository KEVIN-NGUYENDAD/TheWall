15. Gameplay Polish Pass — done (no new features, per explicit instruction; only polished what already existed). 16. Bug Fix Pass — done. Platform gaps (MIN_GAP/MAX_GAP) widened 35% as the shared baseline all difficulty multipliers scale from, restoring a sense of progression the last two passes had flattened out; Easy's platform-count multiplier pulled back from 1.5x to 1.15x (the old 1.5x was over-compensating for tight gaps that no longer exist) for a less densely-packed feel; coin chance cut 30% (0.45 -> 0.315). Winter strengthened to be unmistakable: snow-patch chance on platforms raised 0.2 -> 0.85, snowfall interval tightened 0.18 -> 0.12, cold tint-wash alpha raised 0.3 -> 0.45, sky pushed cooler, fog boost raised 0.35 -> 0.45 — confirmed via a rendered screenshot (snow-capped platforms clearly visible). Found and fixed a real, pre-existing bug while validating the gap increase: Medium/Hard's fully-unconstrained horizontal platform placement (independent of the vertical gap rolled) already produced ~7-9% mathematically-impossible jumps before this pass touched anything — confirmed by testing with the OLD gap values too. Added a physics-based joint reachability cap (mirrors Player.gd's jump kinematics) so the horizontal roll for any difficulty is now bounded by what that step's vertical gap can actually reach at max charge — validated via simulation: 0 impossible jumps across all 3 difficulties, both before and after the widening. Re-validated Easy mode per item 6: still 0% death rate before 50m and 100m (beginner zone intact), but now ~8% death rate past 100m into 300m (was a flat 0% before this pass) — real progression/challenge restored without touching the protected first-100m learning window.
17. Final Beta Gameplay+Visual Pass — done. Platforms replaced the flat per-difficulty scale factor with 4 real width categories (short 60-100px, medium 100-180px, long 180-300px, xlong 300-450px), randomly distributed with difficulty-specific weights (Easy skews long/generous, Hard skews short/narrow) — confirmed via a per-difficulty screenshot showing a stark, immediate visual difference. Gaps moved from a shared-base-times-multiplier system to explicit per-difficulty ranges (Easy 90-180px, Medium 150-260px, Hard 220-355px) — the requested +50-300% figures would have pushed Medium/Hard's vertical gap past the ~432px hard physics ceiling (a single jump can only ever rise so far), which directly contradicts the same request's own non-negotiable "zero impossible jumps" requirement — reachability was prioritized over the literal percentages, with a MAX_SAFE_VERTICAL_GAP hard ceiling added on top so no range can ever exceed it regardless of future tuning. Winter and Storm now override the mountains/hills/far-clouds that the old Zone system otherwise owned (a real root-cause fix, not just another color tweak) — without this, the background stayed Zone-green regardless of season since Zone bands (0/100/500m) don't line up with Season bands (0/100/250/450/700m); confirmed via screenshot that Winter's mountains are now pale icy-white and Storm's are dark grey, both fully distinct from the green default, and that leaving either season correctly restores the normal Zone-driven color. Storm also got denser rain (0.15->0.08 interval), brighter lightning (0.55->0.75 alpha), and an obviously windier WindLayer (2.4x speed+visibility) on top of the darker background. Winter's snow interval tightened further (0.12->0.07) and snow-patch coverage is now near-universal (0.95). Added a small always-on fog floor (0.15) for constant atmospheric depth, and widened the parallax layer speed spread (CloudsFar 0.08->0.04, FogLayer 0.9->0.97) for a stronger 2.5D read. Player's outline and foot-shadow both strengthened further; all 5 platform variants' highlight/shadow/depth polygons had their alpha raised (~40-50% more pronounced). Coin density cut further (0.315->0.22) with a bigger glow to stay visible despite being rarer. LevelUpPopup shrunk again (font 40->32, outline 7->4) since it was still reported as too heavy, plus a scale-in "pop" animation for more polish — still just plain text, no panel, 1.5s hold. Found and fixed a real test-harness-revealed-but-real bug while validating: a second, independent Tween-freezing hazard (the Memory system's pause-on-first-sight, same class of bug as last pass's LevelUpPopup freeze) exists for any Tween racing against a fresh MEMORY_HEIGHTS crossing — not fixed at the source (out of scope, no gameplay symptom found), just documented as a real interaction now that it's been triggered once. Difficulty distinction (Easy=more long platforms+shorter gaps+fewer traps, Hard=more short platforms+farther gaps+more traps) now falls directly out of the width-weight and gap-range tables rather than a single flat multiplier — verified via screenshot that Easy and Hard are immediately, visibly different columns.
