# THE WALL — Project Tree

the actual filesystem (excludes `.godot/` editor cache and `.git/` internals,
both regenerable/non-source). `*.gd.uid` sidecar files (one per script, added
automatically by the Godot 4.7 editor) are omitted from the tree below for
readability — every `.gd` file has a matching `.gd.uid`.

## Notes on items flagged above

- **`node_2d.tscn`** (project root): created when the Godot project was first
  scaffolded, before any of this build's work started. Nothing references it —
  confirmed via grep across `project.godot` and every scene/script. Safe to
  delete whenever someone wants to tidy up; left in place across every doc pass
  so far since no one has been explicitly asked to remove it.
- **`TheWall.bundle`**: a git bundle file (`git bundle list-heads` shows one ref,
  `refs/heads/master`) sitting untracked in the working directory. Almost
  certainly a byproduct of a review/backup tool rather than something authored
  by hand. Not part of the game; see `KNOWN_BUGS.md` for the housekeeping note.
- **`export_presets.cfg`**: one `Android` preset exists, but `package/unique_name`
  is still the Godot-generated placeholder (`com.example.$genname`) and
  `package/name` / `version/name` are empty, with no keystore configured yet.
  See `RELEASE_CHECKLIST.md` before trying to build from this preset.
